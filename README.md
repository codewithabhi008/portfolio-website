## 📌 About The Project

This repository contains my personal portfolio website, created to present my work, technical skills, projects and professional profile in a clean and engaging way.

The website is designed with a focus on:

* 🎨 Clean and modern UI
* 📱 Responsive design
* ⚡ Smooth and interactive user experience
* 💻 Developer-focused presentation
* 📂 Project showcase
* 📄 Resume access
* 🔗 Social and professional links
* 🔍 SEO-friendly structure

The project is built using core web technologies without depending on a heavy frontend framework.

---

## ✨ Features

### 🏠 Home Section

A professional landing section introducing me and highlighting my developer profile.

### 👨‍💻 About Me

A dedicated section containing information about my background, interests and development journey.

### 🛠️ Skills

A visual representation of my technical skills and technologies that I work with.

### 🚀 Projects

A collection of selected projects showcasing my practical development experience.

Each project can be used to understand:

* Project idea
* Development approach
* Technologies used
* Implementation
* Real-world use case

### 📄 Resume

My resume is included in the repository and can be accessed directly from the portfolio.

### 📬 Contact Section

A dedicated section that allows visitors, recruiters and potential collaborators to get in touch.

### 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

### 🔎 SEO Support

The project includes:

* `robots.txt`
* `sitemap.xml`

to help search engines understand and index the website.

## 📂 Project Structure

```text
portfolio_abhi/
│
├── 📄 index.html
├── 🎨 style.css
├── ⚡ script.js
├── 📄 Abhijeet Tiwari_CV.pdf
├── 🤖 robots.txt
├── 🗺️ sitemap.xml
└── 📖 README.md
```

### File Description

**`index.html`**
Contains the complete structure and content of the portfolio website.

**`style.css`**
Contains the website's styling, layout, animations and responsive design rules.

**`script.js`**
Handles client-side interactions and dynamic behaviour.

**`Abhijeet Tiwari_CV.pdf`**
My professional resume.

**`robots.txt`**
Provides crawling instructions for search engine bots.

**`sitemap.xml`**
Helps search engines discover and understand website pages.

## 🚀 Getting Started

Want to run this portfolio locally?

### 1. Clone the repository

```bash
git clone https://github.com/codewithabhi008/portfolio_abhi.git
```

### 2. Navigate to the project

```bash
cd portfolio_abhi
```

### 3. Open the website

Simply open:

```text
index.html
```

in your browser.

### Recommended

For a better development experience, use **VS Code + Live Server**.
